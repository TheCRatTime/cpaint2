# cpaint2
**cpaint2** - highlight your C code.

## Description
There is a clean version of [cpaint](https://github.com/TheCRatTime/cpaint/).

### Features
- **C89**/**ANSI C** code standard.
- **Fast work**: state-machine logic.

### Build
Needed:
- C Compiler
- CMake 3.10 and greater
- GNU Make

```bash
cmake -B build
cd build/
make
```
